# Instruções de instalação

Criar um ambiente virtual

`python -m venv .env`

ativar o ambiente virtual

`source .env/bin/activate.fish`

correr o servidor

`flask --app regtel run --port 1234`

instalar as dependencias de estilos

`cd regtel/static/`

`npm i`

### O servidor roda em

> http://localhost:1234/
